**transform.rs -- Implement QwikTransform with the Traverse trait:**

Replace the current stub with a full `Traverse<'a, ()>` implementation following the validated patterns from the API-MAPPING.md and POC-01. The key methods:

1. **State fields on QwikTransform** (expand the existing struct):
   ```
   - options: TransformOptions (already exists as _options)
   - collected: CollectResult (already exists as _collected -- remove underscore prefix)
   - filename: String (already exists as _filename -- remove underscore prefix)
   - segments: Vec<SegmentData> (already exists)
   - diagnostics: Vec<Diagnostic> (already exists)
   - import_tracker: ImportTracker (NEW -- tracks what imports to add/remove)
   - segment_counter: u32 (NEW -- for disambiguating same-name segments with _N suffix)
   - dollar_call_stack: Vec<String> (NEW -- tracks nesting: current parent display_name)
   ```

2. **ImportTracker struct** (define in transform.rs or import_rewrite.rs):
   ```
   struct ImportTracker {
       qrl_imports: Vec<String>,       // e.g., ["componentQrl", "useTaskQrl"]
       needs_qrl: bool,                // segment strategy needs "qrl"
       needs_inlined_qrl: bool,        // inline strategy needs "inlinedQrl"
       needs_captures: bool,           // inline + captures needs "_captures"
       lazy_imports: Vec<(String, String)>,  // (hash, import_path) for segment strategy
   }
   ```

3. **`impl Traverse<'a, ()> for QwikTransform`** -- implement these hooks:

   a. **`enter_call_expression`**: Detect $-calls using the `is_dollar_call()` method (check if callee is an Identifier in `collected.dollar_imports`). When found:
      - Compute display_name from lexical context (use the collector's DollarCallSite data by matching span, or derive inline)
      - Compute segment hash via `hash::compute_segment_hash(scope, rel_path, display_name)`
      - Record a `SegmentData` in `self.segments`
      - Track the dollar call for nesting: push to `dollar_call_stack`
      - Track needed imports in `import_tracker`

   b. **`exit_call_expression`**: This is where the AST mutation happens. For each $-call detected in enter:
      - Match on entry strategy to decide qrl vs inlinedQrl
      - **Segment strategy**: Replace the `$()` CallExpression with `qrl(i_HASH, "name_HASH")` using the `build_qrl_call` pattern from API-MAPPING.md. For named $-suffixed calls (component$), wrap with `componentQrl(qrl(...))`.
      - **Inline strategy**: Replace with `inlinedQrl(body, "name_HASH")` using `build_inlined_qrl_call` pattern. For named $-suffixed calls, wrap similarly.
      - Pop from `dollar_call_stack` if this was a tracked call.

      **CRITICAL implementation detail for exit_call_expression:** The API-MAPPING recommends using `exit_expression` rather than `exit_call_expression` to get a mutable `&mut Expression` that can be replaced with `*expr = replacement`. In `exit_call_expression` you only get `&mut CallExpression` which cannot be replaced with an arbitrary Expression. Use `exit_expression` instead, matching on `Expression::CallExpression(call)` to check if it's a dollar call, then replacing `*expr` with the built QRL expression.

   c. **`exit_program`**: Insert new import statements at the top of `program.body`:
      - For each entry in `import_tracker.qrl_imports`, build `import { nameQrl } from "@qwik.dev/core"` using `import_rewrite::build_named_import()`
      - If `needs_qrl`, build `import { qrl } from "@qwik.dev/core"`
      - If `needs_inlined_qrl`, build `import { inlinedQrl } from "@qwik.dev/core"`
      - If `needs_captures`, build `import { _captures } from "@qwik.dev/core"`
      - For segment strategy, build lazy import constants: `const i_HASH = () => import("./path")`
      - Insert all new statements before the original program body (prepend)

4. **Helper methods on QwikTransform:**

   - `is_dollar_call(&self, call: &CallExpression) -> Option<DollarCallKind>`: Check if callee is Identifier matching `collected.dollar_imports`. Return `DollarCallKind::RawDollar` for "$", `DollarCallKind::Named(name)` for others.

   - `derive_display_name(&self, call: &CallExpression, ctx: &TraverseCtx) -> String`: Derive the display name from the call's lexical context. Look at the parent AST node: if it's a VariableDeclarator, use the binding name. The callee suffix is appended for named calls (e.g., "Foo" + "_component" for component$).

   - `build_segment_import_path(&self, canonical_filename: &str) -> String`: Build the relative import path: `"./canonical_filename"` (no extension).

5. **DollarCallKind enum** (define in transform.rs):
   ```
   enum DollarCallKind {
       RawDollar,           // $(() => ...)
       Named(String),       // component$(() => ...), useTask$(() => ...), etc.
   }
   ```

```
1. For each input module in config.input:
   a. Create an Allocator
   b. Call parse::parse_module(allocator, &input.code, &input.path)
      - If parse fails, collect diagnostics and continue to next input
      - Set is_type_script/is_jsx flags based on ParseResult.source_type
   c. Call collector::collect(&program, &scoping) to get CollectResult
   d. Build TransformOptions from TransformModulesOptions (resolve defaults):
      - core_module: config.core_module.unwrap_or("@qwik.dev/core")
      - strip_exports: config.strip_exports.unwrap_or(vec![])
      - strip_ctx_name: config.strip_ctx_name.unwrap_or(vec![])
      - is_server: config.is_server.unwrap_or(false)
      - etc.
   e. Create QwikTransform::new(&transform_options, collect_result, &input.path)
   f. Run traverse_mut(&mut qwik_transform, allocator, &mut program, scoping, ())
   g. Generate code from the transformed Program using emit::emit_module()
      - For Phase 8, emit.rs just needs a minimal implementation: use Codegen::new().build(&program) to get JavaScript output. Source maps can be stubbed (return None).
   h. Build a TransformModule for the main module:
      - path: input.path
      - is_entry: false (main modules are not entry points)
      - code: generated JavaScript
      - map: None (source maps in Phase 13)
      - segment: None (main module has no segment metadata)
      - orig_path: Some(input.path)
   i. For each segment in qwik_transform.extracted_segments():
      - Build SegmentAnalysis from SegmentData
      - For segment strategy: the segment code will be generated in Phase 10 (code_move.rs)
        For now, create a placeholder TransformModule with empty code for segments
      - Set is_entry: true for segment modules
   j. Collect all TransformModules and Diagnostics

2. Return TransformOutput with all modules, diagnostics, is_type_script, is_jsx.
```

#[test]
fn test_transform_basic_dollar() {
    let config = TransformModulesOptions {
        input: vec![TransformModuleInput {
            code: r#"import { $ } from '@qwik.dev/core';
export const handler = $(() => console.log('hello'));"#.to_string(),
            path: "test.tsx".to_string(),
        }],
        ..TransformModulesOptions::default()
    };
    let result = transform_modules(config).unwrap();
    // Should have at least 1 module (the main transformed module)
    assert!(!result.modules.is_empty(), "Expected at least one output module");
    let main_module = &result.modules[0];
    // The main module code should contain qrl() (not $())
    assert!(main_module.code.contains("qrl"), "Expected qrl in output: {}", main_module.code);
    assert!(!main_module.code.contains("$(() =>"), "Should not contain raw $() call");
}

#[test]
fn test_transform_component_dollar() {
    let config = TransformModulesOptions {
        input: vec![TransformModuleInput {
            code: r#"import { component$ } from '@qwik.dev/core';
const App = component$(() => {
    return <div>Hello</div>;
});"#.to_string(),
            path: "test.tsx".to_string(),
        }],
        ..TransformModulesOptions::default()
    };
    let result = transform_modules(config).unwrap();
    assert!(!result.modules.is_empty());
    let main_code = &result.modules[0].code;
    // Should contain componentQrl (renamed from component$)
    assert!(main_code.contains("componentQrl"), "Expected componentQrl in output: {}", main_code);
    // Should contain qrl() call wrapping the segment
    assert!(main_code.contains("qrl("), "Expected qrl() call: {}", main_code);
}

#[test]
fn test_transform_inline_strategy() {
    let config = TransformModulesOptions {
        input: vec![TransformModuleInput {
            code: r#"import { $ } from '@qwik.dev/core';
export const handler = $(() => console.log('hello'));"#.to_string(),
            path: "test.tsx".to_string(),
        }],
        entry_strategy: EntryStrategy::Inline,
        ..TransformModulesOptions::default()
    };
    let result = transform_modules(config).unwrap();
    assert!(!result.modules.is_empty());
    let main_code = &result.modules[0].code;
