  <files>oxc-ast-util/Cargo.toml, oxc-ast-util/src/main.rs</files>
  <action>
Create a new Rust binary crate at `oxc-ast-util/` (standalone, NOT inside swc-optimizer/).

**Cargo.toml:**
```toml
[package]
name = "oxc-ast-util"
version = "0.1.0"
edition = "2024"

[dependencies]
oxc = { version = "0.113", features = ["serialize"] }
```

Note on edition: Use `2024` (current Rust edition). If the compiler rejects it (requires nightly or not yet stable on user's toolchain), fall back to `edition = "2021"`.

**src/main.rs** (~60 lines):

Implement exactly the pattern from the research (01-RESEARCH.md "Complete Main Function" section):

1. Read file extension from `std::env::args().nth(1)`. On missing arg, print usage to stderr and exit(1).
2. Read code from stdin via `std::io::stdin().read_to_string()`. On read failure, print error to stderr and exit(1).
3. Determine `SourceType` from extension: construct fake filename `format!("input.{ext}")` and use `SourceType::from_path()`. On unknown extension, print error to stderr and exit(1).
4. Create `Allocator::default()`.
5. Parse with `Parser::new(&allocator, &code, source_type).with_options(ParseOptions { parse_regular_expression: true, ..ParseOptions::default() }).parse()`.
6. Check `ret.panicked` -- if true, eprintln a fatal message and exit(2).
7. Check `ret.errors` -- if non-empty, print count and each error (with source code context via `.with_source_code()`) to stderr. Do NOT exit -- continue to emit partial AST.
8. Convert spans: `let mut program = ret.program; Utf8ToUtf16::new(&code).convert_program(&mut program);`
9. Serialize: branch on `source_type.is_javascript()` to call `program.to_pretty_estree_js_json(false)` or `program.to_pretty_estree_ts_json(false)`.
10. Print JSON to stdout via `println!("{json}")`.

Use these imports:
```rust
use std::io::Read;
use oxc::allocator::Allocator;
use oxc::ast_visit::utf8_to_utf16::Utf8ToUtf16;
use oxc::parser::{ParseOptions, Parser};
use oxc::span::SourceType;
```

Do NOT add `serde_json` as a dependency -- the ESTree methods handle serialization. Do NOT add `clap` -- manual arg parsing for one argument is sufficient.
