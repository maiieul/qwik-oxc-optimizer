Output: Iteration variables correctly handled as function params (not captures) in all affected segment modules, matching SWC golden reference.

Then implement `inject_iteration_params`:

```rust
/// Inject iteration variable parameters into an arrow function's parameter list.
///
/// For a body like `() => { ... }`, replaces the params to get `(_, _1, row) => { ... }`.
/// Uses param_names which has format [event_placeholder, element_placeholder, iter_var1, ...].
fn inject_iteration_params(body_code: &str, param_names: &[String]) -> String {
    if let Some(arrow_pos) = find_arrow_position(body_code) {
        // Find the parameter list: everything before `=>`
        let before_arrow = &body_code[..arrow_pos];
        let after_arrow = &body_code[arrow_pos..]; // includes "=> ..."

        // Find the opening paren of params
        // The body_code starts with the function expression, e.g., "() => ..." or "(ev) => ..."
        // We need to replace everything from first "(" to last ")" before the arrow
        if let Some(open_paren) = before_arrow.find('(') {
            // Find the matching close paren by scanning backwards from arrow position
            let before_arrow_trimmed = before_arrow.trim_end();
            if let Some(close_paren_rel) = before_arrow_trimmed.rfind(')') {
                let param_str = param_names.join(", ");
                let prefix = &body_code[..open_paren + 1]; // up to and including "("
                let suffix_start = close_paren_rel; // position of ")" in before_arrow_trimmed
                // Reconstruct: prefix + new_params + ")" + anything between ")" and "=>" + "=>"...
                let between = &before_arrow[close_paren_rel + 1..arrow_pos];
                return format!("{}{}){}{}", prefix, param_str, between, after_arrow);
            }
        }
    }
    body_code.to_string()
}
```

**Important edge cases:**
- The body_code might be `() => console.log(row.value.id)` (expression body)
- The body_code might be `() => {\n  ...\n}` (block body)
- async arrow functions: `async () => ...` -- the `(` comes after `async `
- The existing `find_arrow_position` already handles nested parens and strings

**Interaction with capture injection:** The param injection must happen BEFORE `inject_captures_into_body` since that function also uses `find_arrow_position`. If params are injected first, the arrow position may shift. To keep things clean, apply param injection first, then pass the result to capture injection.
