For each of these 14 tests, generate a spec file by following this exact process:

**Step 1: Read the snapshot file**
Read `swc-optimizer/core/src/snapshots/qwik_core__test__<name>.snap`. Parse:
- Skip YAML frontmatter (between first and second `---` lines)
- Find `==INPUT==` line; everything after it until the first `=====` separator is the input code
- Split remaining content on `=============================` separator lines
- For each module section: extract module path and flags from separator, code (before `Some(` or `None` line), segment metadata (`/* { JSON } */` block if present)
- Find `== DIAGNOSTICS ==` line; everything after is diagnostics

**Step 2: Read the test config**
Search `swc-optimizer/core/src/test.rs` for the function matching the test name. Extract all non-default `TestInput` fields. Default values:
- filename: "test.tsx", entry_strategy: Segment, minify: Simplify, transpile_ts: false, transpile_jsx: false, preserve_filenames: false, explicit_extensions: false, mode: Test, is_server: None, strip_exports: None, strip_ctx_name: None, strip_event_handlers: false, reg_ctx_name: None, scope: None, core_module: None

**Step 3: Generate ASTs**
For each code block (input + all output modules), run:
```bash
cat <<'ENDOFCODE' | ./oxc-ast-util/target/release/oxc-ast-util <ext>
<code>
ENDOFCODE
```
- Input code: always use `tsx` extension
- Output modules: use extension from module path (.js, .ts, .tsx)
- If oxc-ast-util exits with code 2 (parser panic), note "AST generation failed (parser error)" in the spec

**Step 4: Detect conventions**
Scan ALL output modules for each of the 14 convention patterns:
- CONV-01 (QRL calls): `qrl(`, `qrlDEV(`, `inlinedQrl(`
- CONV-02 (Dollar-to-Qrl): `componentQrl(`, `useTaskQrl(`, etc.
- CONV-03 (JSX transforms): `_jsxSorted(`, `_jsxSplit(`, `_jsxQ(`
- CONV-04 (Signal helpers): `_wrapProp(`, `_wrapSignal(`, `_fnSignal(`, `_getVarProps(`, `_getConstProps(`
- CONV-05 (Capture patterns): `_captures[`
- CONV-06 (Lazy imports): `const i_` followed by `=> import(`
- CONV-07 (PURE annotations): `/*#__PURE__*/`
- CONV-08 (Segment extraction): module marked `(ENTRY POINT)`
- CONV-09 (Code stripping): `"Symbol removed by Qwik Optimizer"`, `_noopQrl(`
- CONV-10 (Const replacement): `isServer`/`isBrowser`/`isDev` replaced with literals
- CONV-11 (Props destructuring): `_rawProps`, `_restProps(`
- CONV-12 (Input binding): `bind:value`, `_val`, `_chk`
- CONV-13 (Sync$ serialization): `_qrlSync(`
- CONV-14 (Hoisted functions): `const _hf0 =`
