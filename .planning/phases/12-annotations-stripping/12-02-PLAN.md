**import_rewrite.rs -- add `build_noop_qrl_call`:**

```rust
pub(crate) fn build_noop_qrl_call<'a>(
    segment_name: &str,
    captures: &[String],
    ctx: &mut TraverseCtx<'a, ()>,
) -> Expression<'a> {
    let name_atom = ctx.ast.atom(segment_name);
    let name_literal = ctx.ast.expression_string_literal(SPAN, name_atom, None);

    let capacity = if captures.is_empty() { 1 } else { 2 };
    let mut arguments = ctx.ast.vec_with_capacity(capacity);
    arguments.push(Argument::from(name_literal));

    if !captures.is_empty() {
        // Build captures array [var1, var2, ...]
        let mut elements = ctx.ast.vec_with_capacity(captures.len());
        for cap in captures {
            let cap_atom = ctx.ast.atom(cap);
            let cap_ref = ctx.ast.expression_identifier(SPAN, cap_atom);
            elements.push(ArrayExpressionElement::from(cap_ref));
        }
        let captures_array = ctx.ast.expression_array(SPAN, elements, None);
        arguments.push(Argument::from(captures_array));
    }

    let noop_atom = ctx.ast.atom("_noopQrl");
    let noop_callee = ctx.ast.expression_identifier(SPAN, noop_atom);
    ctx.ast.expression_call_with_pure(
        SPAN,
        noop_callee,
        None::<Box<'_, TSTypeParameterInstantiation<'_>>>,
        arguments,
        false,
        true, // PURE annotation
    )
}
```

Implement `sync$()` -> `_qrlSync(fn, "stringified_fn")` transformation.

**sync$ behavior (from spec analysis of example_of_synchronous_qrl.md):**

sync$() is a special dollar-suffixed call that does NOT produce a segment. Instead:
- `sync$(function(event, target) { event.preventDefault(); })` becomes `_qrlSync(function(event, target) { event.preventDefault(); }, "function(event,target){event.preventDefault();}")`
- `sync$((event, target) => { event.preventDefault(); })` becomes `_qrlSync((event, target)=>{ event.preventDefault(); }, "(event,target)=>{event.preventDefault();}")`
- `sync$((event, target) => event.preventDefault())` becomes `_qrlSync((event, target)=>event.preventDefault(), "(event,target)=>event.preventDefault()")`

The second argument is a minified string representation of the function body -- whitespace removed, comments removed.

Key: sync$ does NOT create a segment (no hash, no qrl wrapper, no lazy import, no segment module). It's replaced directly with _qrlSync.

**import_rewrite.rs -- add `build_qrl_sync_call`:**

```rust
pub(crate) fn build_qrl_sync_call<'a>(
    fn_expr: Expression<'a>,
    minified_string: &str,
    ctx: &mut TraverseCtx<'a, ()>,
) -> Expression<'a> {
    let str_atom = ctx.ast.atom(minified_string);
    let str_literal = ctx.ast.expression_string_literal(SPAN, str_atom, None);

    let mut arguments = ctx.ast.vec_with_capacity(2);
    arguments.push(Argument::from(fn_expr));
    arguments.push(Argument::from(str_literal));

    let sync_atom = ctx.ast.atom("_qrlSync");
    let sync_callee = ctx.ast.expression_identifier(SPAN, sync_atom);
    ctx.ast.expression_call(
        SPAN,
        sync_callee,
        None::<Box<'_, TSTypeParameterInstantiation<'_>>>,
        arguments,
        false,
    )
}
```

Note: _qrlSync does NOT get PURE annotation (it's not in the PURE list from spec analysis -- sync handlers are side-effectful).
