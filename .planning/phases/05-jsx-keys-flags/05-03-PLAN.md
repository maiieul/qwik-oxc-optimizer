// We propagate when: this element has spread (which implies var_props in SWC),

**Root cause**: SWC's `ConstCollector` in `is_const.rs` treats identifiers as NOT const unless they are imports, exports, or const-declared variables. It also treats ALL member expressions as NOT const (`visit_member_expr` -> `is_const = false`). The OXC `is_child_expression_immutable` function does the opposite: it treats ALL identifiers and member expressions as immutable.

However, we cannot simply flip these to `false` because many identifiers in JSX children ARE immutable -- imports like `dep`, const-declared locals like `signal`, `store`, etc. The key distinction in SWC is:
- **Imports**: immutable (checked via `global.imports.contains_key`)
- **Exports**: immutable (checked via `global.exports.contains_key`)
- **Const-declared locals**: immutable (checked via `const_idents` with `IdentType::Var(true)`)
- **Everything else** (parameters, let/var, unresolved globals): mutable

Since OXC doesn't have SWC's full scope analysis, we need to approximate. The function `is_child_expression_immutable` is called from `transform_jsx_children` at line ~1991, which has access to `module_imports` from the caller. We need to pass this context through.

**Fix**: Change the function signature and behavior:

1. **Add a `module_imports` parameter** to `is_child_expression_immutable`:

```rust
fn is_child_expression_immutable(expr: &Expression<'_>, module_imports: &[crate::types::ImportInfo]) -> bool {
```

2. **Change `Expression::Identifier` handling**:

```rust
// Identifiers: check if this is a known import (immutable) or unknown (mutable).
// SWC uses full scope analysis; we approximate by checking module_imports.
// This correctly treats unresolved globals as mutable while keeping imports immutable.
Expression::Identifier(ident) => {
    let name = ident.name.as_str();
    module_imports.iter().any(|imp| {
        imp.specifiers.iter().any(|spec| spec.local == name)
    })
}
```

3. **Change member expression handling**:

```rust

// reaching this function, so this only affects unhandled member expressions.
Expression::StaticMemberExpression(_)
| Expression::ComputedMemberExpression(_) => false,
```
