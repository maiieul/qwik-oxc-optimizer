**Replace with VisitMut impl #1 -- `ConstReplacer` for identifier replacement:**

Create a struct `ConstReplacer` that holds `replacements: &HashMap<String, bool>` and `ast: &AstBuilder<'a>`. Implement `VisitMut<'a>` for it with a single override:

```rust
fn visit_expression(&mut self, expr: &mut Expression<'a>) {
    if let Expression::Identifier(ident) = expr {
        if let Some(&value) = self.replacements.get(ident.name.as_str()) {
            *expr = self.ast.expression_boolean_literal(SPAN, value);
            return; // No children to walk after replacement
        }
    }
    walk_expression(self, expr); // Default: walk children
}
```

This single override replaces ALL 8 manual functions: `replace_identifiers_in_statements`, `replace_identifiers_in_statement`, `replace_identifiers_in_expression`, `replace_identifiers_in_argument`, `replace_identifiers_in_array_element`, `replace_identifiers_in_declaration`, `replace_identifiers_in_jsx_element`, `replace_identifiers_in_jsx_children`, `replace_identifiers_in_jsx_expression`. The VisitMut walker automatically recurses into every AST node type (statements, declarations, arguments, array elements, JSX expressions) and calls `visit_expression` for all expression-like contexts via `to_expression_mut()`.

**Replace with VisitMut impl #2 -- `DeadBranchEliminator` for simplification + elimination:**

Create a struct `DeadBranchEliminator` that holds `ast: &AstBuilder<'a>`. Implement `VisitMut<'a>` for it with two overrides:

1. `visit_expression` -- simplify logical expressions and unary-not:
```rust
fn visit_expression(&mut self, expr: &mut Expression<'a>) {
    walk_expression(self, expr); // Walk children FIRST (bottom-up simplification)
    simplify_logical_expression(expr, self.ast);
}
```

Note: Walk children FIRST so inner expressions are simplified before outer ones are evaluated. This is bottom-up (post-order) traversal, matching the current behavior where `simplify_logical_expression` recurses into children before simplifying the parent.

2. `visit_statements` -- eliminate dead if-branches in statement lists:
```rust
fn visit_statements(&mut self, stmts: &mut oxc::allocator::Vec<'a, Statement<'a>>) {
    walk_statements(self, stmts); // Walk children first (simplify expressions inside)
    // Then eliminate dead branches at this level
    eliminate_dead_if_statements(stmts, self.ast);
}
```

**Extract `eliminate_dead_if_statements` as standalone function:**

Move the dead-branch-specific logic from the current `eliminate_dead_branches` into a standalone function that operates on a `&mut Vec<Statement>`. This function:
- Iterates statements to find `if` with boolean test values
- Applies `StmtAction::Remove` or `StmtAction::ReplaceWith` as current code does
- Does NOT recursively call itself -- the VisitMut walker handles recursion automatically

**Extract `simplify_logical_expression` as standalone function:**

Keep the existing `simplify_logical_expression` function but remove its recursive calls to itself (lines 496-501). The VisitMut walker handles recursion -- by the time `visit_expression` calls `simplify_logical_expression`, all children have already been simplified by the bottom-up walk.

**Update `replace_build_constants` entry point:**

```rust
pub(crate) fn replace_build_constants<'a>(
    program: &mut Program<'a>,
    options: &TransformOptions,
    allocator: &'a oxc::allocator::Allocator,
) {
    let replacements = build_replacement_map(program, options);
    if replacements.is_empty() {
        return;
    }

    let ast = AstBuilder::new(allocator);

    // Pass 1: Replace identifiers with boolean literals
    let mut replacer = ConstReplacer { replacements: &replacements, ast: &ast };
    replacer.visit_program(program);

    // Pass 2: Simplify logical expressions and eliminate dead branches
    let mut eliminator = DeadBranchEliminator { ast: &ast };
    eliminator.visit_program(program);

    strip_build_constant_imports(&mut program.body, &replacements);
}
```
