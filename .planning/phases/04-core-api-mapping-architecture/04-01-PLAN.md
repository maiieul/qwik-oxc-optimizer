- The `dollar_to_qrl_name()` utility function: strip `$`, append `Qrl` (e.g., `component$` -> `componentQrl`)

**Pattern 3: Import Rewriting (APIM-05)**
- "What this pattern does" summary
- Before/after import comparison from `example_functional_component.md`:
  - Input: `import { $, component$, useStore } from '@qwik.dev/core'`
  - Output main module: `import { componentQrl } from "@qwik.dev/core"`, `import { qrl } from "@qwik.dev/core"`, keeps `useStore` (but only in segment module, not main)
- Complete Rust code for `build_named_import()` using `ctx.ast.module_declaration_import_declaration()`, `ctx.ast.import_specifier()`, `ctx.ast.binding_identifier()`
- Strategy for import management: collect needed imports during traversal, build all in `exit_program` hook
- Rules documented with examples:
  - Remove all $-suffixed specifiers from original imports
  - Add `{name}Qrl` import for each $-suffixed function used
  - Add `qrl` import (segment strategy) or `inlinedQrl` import (inline strategy)
  - Add `_captures` import if any segment has captures
  - Keep non-dollar specifiers unchanged (useStore, useSignal, etc.)
  - Import ordering: new qrl-related imports first, then lazy import consts, then remaining original imports
