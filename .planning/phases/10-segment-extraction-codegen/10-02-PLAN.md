**1. Clarify entry strategy behavior for code output:**

Based on spec file analysis, the entry strategies produce these output shapes:

| Strategy | Segment Code Location | Main Module Call | Segment TransformModule |
|----------|----------------------|------------------|------------------------|
| Segment | Separate file | `qrl(i_HASH, "name")` | has code + is_entry=true |
| Inline | Main module (inlinedQrl body) | `inlinedQrl(body, "name")` | metadata only, empty code, is_entry=false |
| Hoist | Main module (inlinedQrl body) | `inlinedQrl(body, "name")` | metadata only, empty code, is_entry=false |
| Single | Single combined file | `qrl(i_HASH, "name")` | all segments in one file |
| Component | Grouped by component | `qrl(i_HASH, "name")` | grouped segment files |
| Smart | Auto-chosen | varies | varies |
| Hook | Grouped by hook type | `qrl(i_HASH, "name")` | grouped segment files |

For Phase 10, implement:
- **Segment**: Already implemented in 10-01 (separate files with code)
- **Inline**: Already works (body in main module via inlinedQrl). Segment modules should have `is_entry: false` and empty code (metadata only)
- **Hoist**: Same behavior as Inline for code output. Segments defined as top-level const variables in main module
- **Single/Component/Smart/Hook**: For now, treat as equivalent to Segment (separate files). These grouping strategies are refinements that can be tuned in Phase 13

// 7. Build segment modules based on entry strategy
let body_codes = qwik_transform.take_segment_body_codes();
let segments = qwik_transform.extracted_segments();

let is_inline_like = entry_strategy::should_inline(&transform_options.entry_strategy)
    || entry_strategy::should_hoist(&transform_options.entry_strategy);

for seg in segments {
    let segment_analysis = segment_data_to_analysis(seg, &input.path);

    if is_inline_like {
        // Inline/Hoist: segment metadata only, no separate code
        let segment_module = TransformModule {
            path: format!("{}.{}", segment_analysis.canonical_filename, seg.extension),
            is_entry: false,
            code: String::new(),
            map: None,
            segment: Some(segment_analysis),
            orig_path: Some(input.path.clone()),
        };
        all_modules.push(segment_module);
    } else {
        // Segment/Single/Component/Smart/Hook: separate file with code
        let body_code = body_codes
            .iter()
            .find(|(span_start, _)| *span_start == seg.span.0)
            .map(|(_, code)| code.as_str())
            .unwrap_or("");

        let segment_code = code_move::build_segment_code(body_code, seg, &transform_options);
        let normalized_code = emit::normalize_code(&segment_code);

        let segment_module = TransformModule {
            path: format!("{}.{}", segment_analysis.canonical_filename, seg.extension),
            is_entry: true,
            code: normalized_code,
            map: None,
            segment: Some(segment_analysis),
            orig_path: Some(input.path.clone()),
        };
        all_modules.push(segment_module);
    }
}

**3. Fix output file extension handling:**

The spec files show different output extensions based on `transpile_ts`:
- `transpile_ts: true` -> `.jsx` or `.js` extension for output (TypeScript stripped)
- `transpile_ts: false` -> keep original extension (`.tsx`, `.ts`)

Look at spec files to determine the pattern:
- `example_multi_capture.md`: transpile_ts=true, output extensions are `.jsx` (from `.tsx` input)
- `example_1.md`: transpile_ts=false (default), output extensions are `.tsx`

Update `file_extension()` in transform.rs or add extension handling in lib.rs:
```rust
fn output_extension(input_path: &str, transpile_ts: bool) -> String {
    let ext = input_path.rsplit('.').next().unwrap_or("js");
    if transpile_ts {
        match ext {
            "tsx" => "jsx".to_string(),
            "ts" => "js".to_string(),
            other => other.to_string(),
        }
    } else {
        ext.to_string()
    }
}
```

The SegmentData.extension should be set using this logic. Currently it uses `self.file_extension()` which returns the raw input extension.

**1. Add a spec test runner that compares optimizer output against spec expectations:**

Add a new test function in spec_tests.rs that runs the optimizer on each spec and compares output modules against expected modules. This test is NOT expected to pass for all 162 specs yet (JSX, signals, stripping are not implemented). Use a focused approach:

```rust
/// Run optimizer on a curated set of spec files that test segment extraction
/// and verify output modules match expected code.
///
/// This tests CONV-08 (segment extraction) and CONV-06 (lazy imports).
/// Specs requiring JSX, signals, or stripping (Phase 11-12) are excluded.
#[test]
fn test_segment_extraction_specs() {
    use qwik_optimizer_oxc::transform_modules;

    let specs = spec_parser::load_all_specs();

    // Select specs that test segment extraction without requiring JSX/signal transforms
    let segment_specs: Vec<&spec_parser::SpecFile> = specs.iter()
        .filter(|s| {
            // Include specs that don't require JSX compilation or signal transforms
            // Focus on: basic $(), component$, captures, entry strategies
            let name = &s.name;
            name.starts_with("example_1")
                || name.starts_with("example_2")
                || name.starts_with("example_multi_capture")
                || name.starts_with("example_capture_imports")
                || name.starts_with("example_inlined_entry_strategy")
                || name.starts_with("should_extract_single_qrl")
        })
        .collect();

    if segment_specs.is_empty() {
        eprintln!("WARNING: No segment extraction specs found to test");
        return;
    }

    let mut pass_count = 0;
    let mut fail_count = 0;
    let mut failures: Vec<String> = Vec::new();

    for spec in &segment_specs {
        let options = spec_parser::build_options(spec);
        let result = match transform_modules(options) {
            Ok(r) => r,
            Err(e) => {
                failures.push(format!("{}: transform failed: {}", spec.name, e));
                fail_count += 1;
                continue;
            }
        };

        // Compare number of output modules
        let expected_count = spec.expected_modules.len();
        let actual_count = result.modules.len();

        if actual_count != expected_count {
            failures.push(format!(
                "{}: expected {} modules, got {}",
                spec.name, expected_count, actual_count
            ));
            fail_count += 1;
            continue;
        }

        // For each expected module, find matching actual module by path
        let mut spec_pass = true;
        for expected in &spec.expected_modules {
            let actual = result.modules.iter().find(|m| {
                // Flexible path matching: compare basenames
                let expected_base = expected.path.rsplit('/').next().unwrap_or(&expected.path);
                let actual_base = m.path.rsplit('/').next().unwrap_or(&m.path);
                expected_base == actual_base
            });

            match actual {
                None => {
                    failures.push(format!(
                        "{}: missing module '{}'",
                        spec.name, expected.path
                    ));
                    spec_pass = false;
                }
                Some(actual) => {
                    // Compare entry status
                    if expected.is_entry != actual.is_entry {
                        failures.push(format!(
                            "{}: module '{}' is_entry mismatch (expected {}, got {})",
                            spec.name, expected.path, expected.is_entry, actual.is_entry
                        ));
                        spec_pass = false;
                    }

                    // Compare code (normalize whitespace for comparison)
                    if !expected.code.is_empty() && !actual.code.is_empty() {
                        let expected_norm = normalize_whitespace(&expected.code);
                        let actual_norm = normalize_whitespace(&actual.code);
                        if expected_norm != actual_norm {
                            failures.push(format!(
                                "{}: module '{}' code mismatch\n  EXPECTED:\n{}\n  ACTUAL:\n{}",
                                spec.name, expected.path,
                                expected.code.lines().take(5).collect::<Vec<_>>().join("\n"),
                                actual.code.lines().take(5).collect::<Vec<_>>().join("\n"),
                            ));
                            spec_pass = false;
                        }
                    }

                    // Compare segment metadata if present
                    if let (Some(expected_seg), Some(actual_seg)) = (&expected.segment, &actual.segment) {
                        // Compare key fields
                        let actual_json = serde_json::to_value(actual_seg).unwrap();
                        let fields = ["ctxName", "ctxKind", "captures", "hash"];
                        for field in &fields {
                            let expected_val = expected_seg.get(field);
                            let actual_val = actual_json.get(field);
                            if expected_val != actual_val {
                                failures.push(format!(
                                    "{}: module '{}' segment.{} mismatch (expected {:?}, got {:?})",
                                    spec.name, expected.path, field, expected_val, actual_val
                                ));
                                spec_pass = false;
                            }
                        }
                    }
                }
            }
        }

        if spec_pass {
            pass_count += 1;
        } else {
            fail_count += 1;
        }
    }

    eprintln!(
        "Segment extraction spec tests: {}/{} passed ({} failed)",
        pass_count,
        pass_count + fail_count,
        fail_count
    );

    if !failures.is_empty() {
        eprintln!("Failures:\n{}", failures.join("\n\n"));
    }

    // For now, assert that at least SOME specs pass (not all, since JSX etc. not yet implemented)
    assert!(pass_count > 0, "At least some segment extraction specs should pass");
}

fn normalize_whitespace(s: &str) -> String {
    s.split_whitespace().collect::<Vec<_>>().join(" ")
}
```

/// Run optimizer on ALL specs and report pass/fail counts.
/// This is an informational test -- it does NOT assert all pass.
/// It gives visibility into overall spec coverage.
#[test]
fn test_all_specs_coverage_report() {
    use qwik_optimizer_oxc::transform_modules;

    let specs = spec_parser::load_all_specs();
    let mut transform_ok = 0;
    let mut transform_err = 0;
    let mut module_count_match = 0;
    let mut module_count_mismatch = 0;

    for spec in &specs {
        let options = spec_parser::build_options(spec);
        match transform_modules(options) {
            Ok(result) => {
                transform_ok += 1;
                if result.modules.len() == spec.expected_modules.len() {
                    module_count_match += 1;
                } else {
                    module_count_mismatch += 1;
                }
            }
            Err(_) => {
                transform_err += 1;
            }
        }
    }

    eprintln!(
        "\n=== Spec Coverage Report ===\n\
         Total specs: {}\n\
         Transform OK: {}\n\
         Transform Error: {}\n\
         Module count match: {}\n\
         Module count mismatch: {}\n\
         ===========================\n",
        specs.len(),
        transform_ok,
        transform_err,
        module_count_match,
        module_count_mismatch
    );

    // All specs should at least transform without errors
    assert!(
        transform_err == 0,
        "All specs should transform without errors, but {} failed",
        transform_err
    );
}
