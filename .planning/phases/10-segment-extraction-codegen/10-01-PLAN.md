**3. Implement code_move.rs:**

Replace the stub with a working implementation. The file should contain:

```rust
use crate::types::{SegmentAnalysis, SegmentData, TransformOptions};
use crate::emit::{EmitOptions, emit_module};

/// Build a segment's JavaScript source code.
///
/// Takes the serialized body code and segment metadata, constructs a
/// complete JavaScript module string with:
/// 1. Framework imports (import { X } from "@qwik.dev/core")
/// 2. _captures import (if segment has captures)
/// 3. Lazy import declarations (const i_hash = () => import(...))
/// 4. Export declaration (export const name = body)
///
/// Returns the complete JavaScript module source code.
pub(crate) fn build_segment_code(
    body_code: &str,
    segment: &SegmentData,
    options: &TransformOptions,
) -> String {
    let mut parts: Vec<String> = Vec::new();

    // 1. Add _captures import if segment has captures
    if segment.captures {
        parts.push(format!(
            "import {{ _captures }} from \"{}\";",
            options.core_module
        ));
    }

    // 2. Add needed framework imports (for segments with nested $-calls)
    // These come from segment.needed_imports (populated during transform)
    for import_info in &segment.needed_imports {
        if import_info.is_qwik_core {
            for spec in &import_info.specifiers {
                parts.push(format!(
                    "import {{ {} }} from \"{}\";",
                    spec, options.core_module
                ));
            }
        } else {
            // User imports: re-emit as-is
            for spec in &import_info.specifiers {
                parts.push(format!(
                    "import {{ {} }} from \"{}\";",
                    spec, import_info.source
                ));
            }
        }
    }

    // 3. Build the export declaration with capture restoration
    let segment_name = &segment.name;
    if segment.captures && !segment.capture_names.is_empty() {
        // Build capture restoration statements:
        // const varName = _captures[0]; const varName2 = _captures[1]; etc.
        let capture_stmts: Vec<String> = segment
            .capture_names
            .iter()
            .enumerate()
            .map(|(i, name)| format!("const {} = _captures[{}];", name, i))
            .collect();

        // Parse the body_code to determine if it's an arrow with block body or expression body
        // For block body: inject capture restoration after opening {
        // For expression body: wrap in block with capture restoration
        let modified_body = inject_captures_into_body(body_code, &capture_stmts);
        parts.push(format!("export const {} = {};", segment_name, modified_body));
    } else {
        parts.push(format!("export const {} = {};", segment_name, body_code));
    }

    parts.join("\n")
}
```

**ALTERNATIVE SIMPLER APPROACH for code_move.rs:** Instead of AST construction via AstBuilder (which requires an allocator and complex lifetime management), **generate the segment module source code as a string**, then parse+codegen to normalize formatting. This is simpler because:
- The body_code is already a string
- We just need to prepend imports and wrap in `export const`
- Re-parsing normalizes formatting to match spec expectations

Implement `build_segment_code()` as a string builder that:
1. Prepends `import { _captures } from "@qwik.dev/core";` if captures exist
2. Prepends any needed framework imports (qrl, useStore, etc.)
3. Prepends lazy import constants for child segments
4. Wraps body in `export const NAME = BODY;`
5. Injects `const varName = _captures[N];` statements into the body if captures exist

For capture injection into the body string: The body is an arrow function like `() => { ... }` or `(_rawProps) => { ... }`. For block bodies (containing `{`), insert capture restoration after the opening `{`. For expression bodies, wrap in a block first.

The function `inject_captures_into_body(body_code: &str, capture_stmts: &[String]) -> String` should:
- Find the first `{` after the arrow `=>`
- If found: insert capture stmts after it (block body)
- If not found (expression body like `() => expr`): convert to `() => { const x = _captures[0]; return expr; }`

**4. Add `emit_segment` helper to emit.rs (optional):**

The current `emit_module` works for Program ASTs. For the string-based approach, we may not need a separate emit function -- the segment code is already a string. However, to normalize formatting, we can parse the string and re-emit:

```rust
pub(crate) fn normalize_code(code: &str) -> String {
    let allocator = oxc::allocator::Allocator::default();
    let source_in_arena = allocator.alloc_str(code);
    let source_type = oxc::span::SourceType::mjs();
    let ret = oxc::parser::Parser::new(&allocator, source_in_arena, source_type).parse();
    if ret.panicked || !ret.errors.is_empty() {
        // If parsing fails, return original code unchanged
        return code.to_string();
    }
    oxc::codegen::Codegen::new()
        .with_source_text(source_in_arena)
        .build(&ret.program)
        .code
}
```

**2. Implement finalize_segments() on QwikTransform (transform.rs):**

```rust
/// Post-transform processing: populate child segment metadata.
/// Must be called after traverse_mut completes.
pub fn finalize_segments(&mut self) {
    // Build a map of parent_name -> Vec<child segment info>
    let child_info: Vec<(String, String, String)> = self.segments
        .iter()
        .filter_map(|seg| {
            seg.parent.as_ref().map(|parent_name| {
                let canonical = format!("{}_{}", seg.display_name, seg.hash);
                let import_path = format!("./{}", canonical);
                (parent_name.clone(), seg.hash.clone(), import_path)
            })
        })
        .collect();

    // For each parent segment, add child lazy imports
    for seg in self.segments.iter_mut() {
        let children: Vec<_> = child_info
            .iter()
            .filter(|(parent, _, _)| parent == &seg.display_name)
            .collect();

        if !children.is_empty() {
            seg.needs_qrl_import = true;
            for (_, hash, path) in children {
                seg.child_lazy_imports.push((hash.clone(), path.clone()));
            }
        }
    }
}
```
