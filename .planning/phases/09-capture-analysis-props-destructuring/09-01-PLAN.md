<objective>
Implement CONV-11 props destructuring transformation for component$ arrow functions.

Purpose: When a component$ callback uses destructured props `({foo, bar, ...rest})`, the optimizer must rewrite the parameter to `_rawProps` and replace all body references to destructured names with `_rawProps.key` member access. Rest patterns produce `const rest = _restProps(_rawProps, ["foo", "bar"])`. This must run before capture analysis (Plan 09-02) because it changes the scope bindings that capture analysis reads.

Output: Working props_destructuring.rs that transforms destructuring patterns and integrates with the QwikTransform traverse pass.
</objective>

  <action>
Replace the stub in props_destructuring.rs with the full implementation. The function operates on a component$ callback's FormalParameters and FunctionBody during the Traverse pass.

**Detection logic:**
1. Check if the arrow function's first parameter is an ObjectPattern (destructured props). If it is a plain BindingIdentifier (e.g., `(props) =>`), skip -- no transformation needed.
2. Extract all property keys from the ObjectPattern:
   - For `ObjectProperty` with `BindingIdentifier` value: the key is the property name, the local name is the identifier name. E.g., `{foo}` -> key="foo", local="foo". `{count: c}` -> key="count", local="c".
   - For `RestElement`: the rest variable name. E.g., `{...rest}` -> rest_name="rest".
3. Track: `prop_keys: Vec<(String, String)>` (original_key, local_alias) and `rest_name: Option<String>`.

**Parameter rewrite:**
Replace the ObjectPattern parameter with a single BindingIdentifier `_rawProps`. Use `ctx.ast.binding_pattern_binding_identifier(SPAN, ctx.ast.atom("_rawProps"))` to build the new parameter, then replace the first formal parameter's `pattern` field.

**Body rewrite -- conceptual approach:**
The body rewrite requires replacing all IdentifierReference nodes that match destructured local names with MemberExpression nodes `_rawProps.key`. This is complex to do in-place during traversal because we need to replace `Expression::Identifier` nodes with `Expression::StaticMemberExpression` nodes.

**Implementation strategy -- post-traversal rewrite using collected info:**
Rather than mutating the AST in props_destructuring.rs directly (which would fight the borrow checker), take a simpler approach that works with OXC's traversal:

1. `analyze_props_destructuring()` -- a pure analysis function that examines the first parameter and returns a `PropsDestructuringInfo` struct:
   ```rust
   pub(crate) struct PropsDestructuringInfo {
       pub needs_transform: bool,
       pub prop_keys: Vec<(String, String)>,  // (original_key, local_alias)
       pub rest_name: Option<String>,
       pub raw_props_name: String,  // "_rawProps" normally
   }
   ```

2. The actual AST mutation happens in the QwikTransform Traverse pass:
   - In `enter_call_expression` for a detected component$ call, call `analyze_props_destructuring()` on the arrow function argument.
   - If `needs_transform`, store the PropsDestructuringInfo on QwikTransform.
   - In `exit_expression` for the component$ call, before building the QRL replacement, rewrite the parameter and body using the stored info.
   - Parameter rewrite: replace the ObjectPattern with `_rawProps` BindingIdentifier.
   - For rest patterns, prepend `const rest = _restProps(_rawProps, ["key1", "key2"])` to the body.
   - Body reference rewriting: Walk the body statements and replace Identifier references matching local aliases with `_rawProps.original_key` member expressions. This is done via a dedicated recursive walk function `rewrite_props_references()` that matches on Expression::Identifier and replaces with StaticMemberExpression or ComputedMemberExpression.

3. The `_restProps` import is tracked on ImportTracker (add `needs_rest_props: bool` field).

**Type additions in types.rs:**
Add to SegmentData a field `param_names: Vec<String>` to track the rewritten parameter names (e.g., `["_rawProps"]`). This corresponds to the `paramNames` field seen in spec metadata. Also add `param_names` to SegmentAnalysis for serialization (as `#[serde(skip_serializing_if = "Option::is_none")]`).

**Key OXC patterns (from Phase 8 decisions):**
- Use `ctx.ast.atom()` for arena string allocation
- Use `ctx.ast.vec_with_capacity()` for building new Vec
- Use `std::mem::swap` + `ctx.ast.vec()` for extracting/replacing OXC vecs
- BindingPattern is a flat enum in OXC 0.113 (match on BindingPattern::ObjectPattern directly)

**Tests in props_destructuring.rs:**
- test_analyze_simple_destructuring: `({foo, bar}) =>` detects 2 props, no rest
- test_analyze_rest_pattern: `({foo, ...rest}) =>` detects 1 prop + rest
- test_analyze_renamed_props: `({count: c}) =>` detects key="count", local="c"
- test_analyze_plain_identifier: `(props) =>` returns needs_transform=false
- test_analyze_no_params: `() =>` returns needs_transform=false

3. In `enter_call_expression`: When a component$ call is detected (DollarCallKind::Named("component$")):
   - Check if the first argument is an ArrowFunctionExpression
   - Call `props_destructuring::analyze_props_destructuring()` on the arrow's params
   - If `needs_transform`, store the info in `self.active_props_info`
   - If the info has a rest_name, set `self.import_tracker.needs_rest_props = true`

4. In `exit_expression`: When processing a component$ call with `active_props_info.is_some()`:
   - Before building the QRL replacement, rewrite the arrow function:
     a. Replace the first parameter's ObjectPattern with `_rawProps` BindingIdentifier

     c. Walk the body and replace identifier references matching the local aliases with `_rawProps.{original_key}` member expressions via `props_destructuring::rewrite_props_references()`
   - Set `segment.param_names = vec!["_rawProps".to_string()]` on the segment data

5. In `exit_program`: Add `_restProps` import if `self.import_tracker.needs_rest_props` is true.

6. In `record_segment`: If `active_props_info` is set (i.e., we're inside a component$ with destructured props), set `segment.param_names = vec!["_rawProps".to_string()]`.

**Building _restProps call AST:**
Use the same patterns from import_rewrite.rs to build:
```
_restProps(_rawProps, ["key1", "key2"])
```
This is a CallExpression with identifier callee `_restProps`, two arguments: identifier `_rawProps` and an ArrayExpression of StringLiteral elements for each non-rest key.

**Building member expression replacement:**
For `foo` -> `_rawProps.foo`:
```rust
ctx.ast.expression_member(SPAN,
    ctx.ast.expression_identifier(SPAN, ctx.ast.atom("_rawProps")),
    ctx.ast.identifier_name(SPAN, ctx.ast.atom("foo")),
    false // not computed
)
```
Use `expression_static_member` or the equivalent OXC 0.113 API.
