- Stringification: use `oxc_codegen::Codegen::new()` with minification options to serialize the function body, remove comments, minify whitespace
- Result goes into varProps (not constProps) of JSX call
- OXC construction: `ast.expression_call(_qrlSync_ident, vec![fn_expr, ast.expression_string_literal(minified)])`
- Reference `example_of_synchronous_qrl.md` for complete example

OXC API for building noop replacements:
- Prod: `ast.expression_call(_noopQrl_ident, vec![ast.expression_string_literal(hash)])`
- Dev: `ast.expression_call(_noopQrlDEV_ident, vec![ast.expression_string_literal(name), debug_object])`
- Debug object: same `{file, lo, hi, displayName}` structure as qrlDEV
- Import: `_noopQrl` or `_noopQrlDEV` from `@qwik.dev/core`

**12. Nested $() Preservation (Section 12)**
Document the rule that `$()` and `client$()` calls INSIDE a stripped callback body are NOT stripped:
- They produce their own segments normally
- Only the outer stripped call gets the noop replacement
- Implementation: during stripping pass, track "inside stripped body" state but do NOT suppress inner `$()` processing

**13. Side Effect Analysis for Dead Declaration Removal (Section 13)**
Document the algorithm using oxc_semantic:
- After stripping: some imports and declarations may have zero remaining live references
- Algorithm: (a) collect all stripped segment body bindings, (b) for each declaration in the module, check if ALL references are inside stripped bodies, (c) if yes, remove the declaration, (d) for imports, remove the import specifier (and the entire import statement if no specifiers remain)
- Preserved patterns (NEVER removed): IIFEs `(function(){ ... })()`, standalone function calls `sideEffect()`, arrow IIFEs `(() => { ... })()`
- OXC API: Use `semantic.symbol_references(symbol_id)` to check reference count, `semantic.symbol_declaration(symbol_id)` to find the declaration node

Provide a Rust pseudocode function `remove_dead_declarations()` showing the reference analysis loop.

Reference `example_drop_side_effects.md` for the side effect preservation examples.

**14. Export Stripping (Section 14)**
Document the throw replacement for stripped exports:
- When an entire exported function/class is server-only, body is replaced with `throw "Symbol removed by Qwik Optimizer..."`
- OXC construction: `ast.expression_throw(ast.expression_string_literal("Symbol removed by Qwik Optimizer..."))`
- Reference `example_strip_server_code.md` for the export stripping example

**15. Const Replacement / isServer (Section 15)**
Document CONV-10 const folding:
- Detection: `enter_identifier_reference` -> check if identifier is `isServer` imported from `@qwik.dev/core`
- Replacement: `ast.expression_boolean_literal(is_server_value)` where `is_server_value` depends on build target
- Dead branch elimination after replacement:
  - `if (false) { ... }` -> remove the entire if statement
  - `if (true) { ... }` -> keep only the body (unwrap the if)
  - `!false` -> `true`, `!true` -> `false`
- OXC API for dead branch removal: match on `IfStatement.test` being `BooleanLiteral`, then either remove or replace with consequent block

**16. Static Expression Evaluation (Section 16)**
Document the mini constant folder:
- String concatenation: `'true' + 1` -> `"true1"`
- Ternary with known condition: `"true1" ? 'true' : ''` -> `'true'` (truthy string)
- Template literals: `` `text${12}` `` -> `"text12"`
- typeof: `typeof "text12"` -> `"string"`
- Scope: only handle literals and simple operations, NOT function calls or complex expressions

Provide a Rust function `try_eval_const_expr()` returning `Option<ConstValue>` for the evaluable cases.
