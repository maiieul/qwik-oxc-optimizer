Create a new Rust integration test file `output_audit.rs` that performs semantic comparison of OXC optimizer output against spec expected output for all 162 specs. This is a one-time audit tool, not a permanent regression test.

The test should:

1. **Load all specs** using `spec_parser::load_all_specs()` and `spec_parser::build_options()`.

2. **Run the optimizer** on each spec via `qwik_optimizer_oxc::transform_modules()`.

3. **Match modules**: For each spec, pair expected modules (from `spec.expected_modules`) with actual modules (from `result.modules`) by path. Since hashes differ between SWC and OXC, match by:
   - Exact path match first (for the main module, e.g., "test.tsx")
   - For segment modules: match by stripping the hash portion and comparing the structural path prefix. The expected path like `test.tsx_renderHeader_zBbHWn4e8Cg.tsx` maps to actual `test.tsx_renderHeader_OTHERHASH.tsx` -- match on the part before the hash. Use the segment metadata `display_name` or `ctx_name` as fallback disambiguation.
   - Track unmatched modules on both sides (extra actual, missing expected).

4. **Normalize and compare code** for each matched module pair:
   - Strip all whitespace (collapse multiple spaces/newlines to single space, trim). The user decision is "ignore all whitespace differences."
   - Sort import lines alphabetically before comparing (import ordering does not matter).
   - Compare the normalized strings. If they differ, record the deviation.
   - Do NOT ignore const/let/var differences -- these are meaningful per user decision.

5. **Record deviations** as structured data. Each deviation should include:
   - `spec_name`: string
   - `module_path_expected`: string (the spec's path)
   - `module_path_actual`: string (the optimizer's path)
   - `match_type`: "exact_path" | "structural" | "unmatched_expected" | "unmatched_actual"
   - `expected_code_normalized`: string (normalized expected)
   - `actual_code_normalized`: string (normalized actual)
   - `diff_summary`: brief description of what differs (e.g., "missing capture variable 'count'", "const vs let", "different QRL wrapper", "extra import")

6. **Serialize results to JSON** and write to `.planning/phases/23-output-audit/audit-raw.json`. The JSON structure:

     }
   }
   ```

7. **Print a summary** to stderr for the test runner showing pass/fail/deviation counts.

fn normalize_code(code: &str) -> String {
    let lines: Vec<&str> = code.lines().collect();
    let (mut imports, mut non_imports): (Vec<String>, Vec<String>) = (vec![], vec![]);
    for line in &lines {
        let trimmed = line.trim();
        if trimmed.starts_with("import ") {
            imports.push(trimmed.split_whitespace().collect::<Vec<_>>().join(" "));
        } else if !trimmed.is_empty() {
            non_imports.push(trimmed.split_whitespace().collect::<Vec<_>>().join(" "));
        }
    }
    imports.sort();
    let mut result = imports;
    result.extend(non_imports);
    result.join(" ")
}
```
