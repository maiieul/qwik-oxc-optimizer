**Guard:** Only transform JSX when `options.transpile_jsx` is true. When false, JSX passes through untouched (the optimizer still processes $() calls and event handler attributes within JSX, but doesn't convert JSXElement nodes to function calls).

**ImportTracker additions (transform.rs):**
Add fields to ImportTracker:
- `needs_jsx_sorted: bool` -- import `_jsxSorted` from `@qwik.dev/core`
- `needs_jsx_split: bool` -- import `_jsxSplit` from `@qwik.dev/core`
- `needs_get_var_props: bool` -- import `_getVarProps` from `@qwik.dev/core`
- `needs_get_const_props: bool` -- import `_getConstProps` from `@qwik.dev/core`
- `needs_fragment: bool` -- import `Fragment as _Fragment` from `@qwik.dev/core/jsx-runtime`
- `jsx_key_counter: u32` -- monotonic counter for generating unique key suffixes like `"u6_0"`, `"u6_1"`

**Traverse method: `exit_jsx_element`** (new method on `impl Traverse for QwikTransform`):
When `transpile_jsx` is true, this replaces a `JSXElement` with a function call expression.

Algorithm:
1. **Tag extraction:** If opening element name is a JSXIdentifier with lowercase first char, it's a native element -- tag is a string literal `"div"`. If uppercase, it's a component reference -- tag is an identifier expression `Cmp`. For JSXMemberExpression (e.g., `Foo.Bar`), build a member expression.

2. **Prop classification:** Iterate over `opening_element.attributes`:
   - If ANY attribute is a `JSXSpreadAttribute`, the entire element uses `_jsxSplit` instead of `_jsxSorted`.
   - For `_jsxSorted`, separate attributes into var props and const props objects:
     - **Event handlers:** Attributes ending in `$` that are event-like (onClick$, onDocumentScroll$, on-cLick$, host:onClick$, document:onFocus$, window:onClick$) get renamed: strip the scope prefix (on/onDocument/onWindow/host:on) and `$` suffix, lowercase the event name, add `q-e:` prefix. For example: `onClick$` -> `"q-e:click"`, `onDocumentScroll$` -> `"q-e:document:scroll"`, `window:onClick$` -> `"q-e:window:click"`, `host:onClick$` -> still `"q-e:click"` (host is deprecated). The value goes into **const props**. When the value is an arrow/function literal (inline handler), it should be treated as a $()-call (the optimizer already extracts these as segments when they are `$()` calls; event handler attributes with literal arrow functions become qrl()-wrapped segments).
     - **`key` attribute:** Extracted separately as the key argument (6th arg). NOT placed in var or const props.
     - **All other attributes:** Classify based on expression constness:
       - Const: string literals, numeric literals, boolean literals, template literals with no expressions, `null`, `undefined`. Go into **const props**.
       - Var: everything else (identifiers, member expressions, call expressions, computed expressions, JSX expression containers). Go into **var props**.
     - If var props object would be empty, pass `null`. If const props would be empty, pass `null`.
   - For `_jsxSplit`, ALL attributes (including spreads) go into a single props object as the 2nd argument. Use `_getVarProps(props)` and `_getConstProps(props)` for spread elements.

3. **Children encoding:**
   - No children: `null`
   - Single child that is a JSXElement/JSXFragment/JSXExpressionContainer with non-trivial expression: pass directly
   - Multiple children: array expression
   - Skip `JSXText` nodes that are whitespace-only (trim, check if empty)
   - Non-whitespace JSXText becomes a string literal

4. **Flags computation:**
   - `0` = has spreads
   - `1` = has multiple or dynamic children (array children, .map() calls)
   - `2` = only has event handler props (no visible props)
   - `3` = simple leaf / no children / single static child
   - Use pattern matching from spec analysis. The key insight: flags=3 for self-closing tags and tags with simple/no children; flags=1 for tags with array children or multiple JSX children.

5. **Key generation:**
   - If `key` attribute exists, use its value expression
   - If no key attribute, generate a stable key using the counter: string literal `"u6_N"` where N is the jsx_key_counter (increment after use). Only generate auto-keys for elements that have children or siblings in an array context. Elements without a key and without siblings get `null` as key.
   - IMPORTANT: Study the spec outputs carefully. Some elements get `null` key (standalone, no siblings), others get auto-generated `"u6_N"`. The pattern: elements that are direct children of a component (returned from component body) get auto-keys. Elements inside `.map()` loops with explicit `key` prop use that key.

6. **Build the call expression:** `_jsxSorted(tag, varProps, constProps, children, flags, key)` or `_jsxSplit(tag, props, constProps, children, flags, key)`. Mark with PURE annotation.

**Traverse method: `exit_jsx_fragment`** (new method):
Replace `<>...</>` with `_jsxSorted(_Fragment, null, null, children, flags, key)`. Set `needs_fragment = true`.

**Import additions in `exit_program`:**
- Add imports for `_jsxSorted`, `_jsxSplit`, `_getVarProps`, `_getConstProps` from `core_module`
- Add `Fragment as _Fragment` import from `@qwik.dev/core/jsx-runtime` (NOT from core_module -- this is a special import source)
- Use `build_named_import` for standard imports. For Fragment aliased import, create a new helper `build_aliased_import(imported_name, local_name, source, ctx)` in import_rewrite.rs.

**import_rewrite.rs additions:**
- `build_aliased_import()`: Like `build_named_import` but with different imported vs local names. Used for `import { Fragment as _Fragment } from "@qwik.dev/core/jsx-runtime"`.

**Key reference files for _jsxSorted signature:**
```
_jsxSorted(tag, varProps, constProps, children, flags, key)
```
- tag: string literal (native) or identifier (component)
- varProps: object expression or null
- constProps: object expression or null
- children: null, expression, or array expression
- flags: numeric literal (0, 1, 2, or 3)
- key: string literal, expression, or null

**OXC API patterns to use (from prior phases):**
- `ctx.ast.expression_string_literal(SPAN, atom, None)` for string tags/keys
- `ctx.ast.expression_numeric_literal(SPAN, value, raw, NumberBase::Decimal)` for flags
- `ctx.ast.expression_null_literal(SPAN)` for null args
- `ctx.ast.expression_object(SPAN, properties)` for prop objects
- Object properties: `ctx.ast.object_property(SPAN, kind, key, value, ...)` for each prop
- `ctx.ast.expression_call_with_pure(SPAN, callee, type_params, args, optional, pure)` for PURE-annotated calls
