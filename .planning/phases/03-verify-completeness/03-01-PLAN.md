Create `.planning/tools/fix-specs.py` -- a Python 3 script that reads all 162 spec files and applies deterministic normalization. The script applies these transformations IN THIS ORDER:

1. **Module heading backticks:** Replace `` ### Module: `path` `` with `### Module: path` using regex: `re.sub(r'^(### Module: )`([^`]+)`', r'\1\2', content, flags=re.MULTILINE)`

2. **Entry point notation:** Replace `[ENTRY POINT]` with `(ENTRY POINT)` globally.

3. **Extra module annotations:** Remove `(main)`, `(main module)`, `(main, Inline -- single module)` and similar suffixes from module headings. Regex: strip ` (main...)` patterns from lines starting with `### Module:` but preserve `(ENTRY POINT)`.

4. **Config prose to table:** Find `## Test Configuration` sections that contain prose instead of a table. Replace with table format:
   - If text is "All defaults..." or similar, replace with:
     ```
     | Option | Value |
     |--------|-------|
     | *(all defaults)* | |
     ```
   - Detection: section after `## Test Configuration\n\n` does NOT start with `|`

5. **Config value backticks:** In config tables, remove backtick wrapping from values. Regex on table rows: `re.sub(r'\| `([^`]+)` \|', r'| \1 |', line)`

6. **Diagnostics normalization:** Find `## Diagnostics` section and normalize:
   - If content is "No diagnostics.", "None", "None (`[]`)", or similar non-code-block format, replace with:
     ```
     ## Diagnostics

     ```json
     []
     ```
     ```
   - If content is bare `[]` (not in code fence), wrap it in json code fence
   - If content is already ` ```json\n...\n``` `, leave it alone

7. **No-conventions text:** Replace "None --", "**None**", or other non-standard no-conventions text in `## Conventions Applied` section with `*No optimizer conventions detected in output.*`

CRITICAL PRESERVATION RULES:
- Do NOT modify `**Key behavior:**` notes -- these are valuable and must be preserved exactly
- Do NOT modify convention descriptions (the text after `[CONV-XX] Name:`) -- only normalize the "no conventions" case
- Do NOT modify code blocks inside ``` fences
- Do NOT modify `<details>` blocks or their contents
- Do NOT touch segment metadata sections
- The `relative_paths.md` file uses `### Input Modules` subsection -- this is a legitimate exception, do not break it
